# 高风险销售内容影响范围与复核覆盖分析

本地资料用于理解审核内容传播影响范围所涉及的记录关系。文件均为合成数据，标识符不对应真实个人、机构或账号。

## 目录

- `content_impact/`：从内容证据到传播影响范围的分析包，仅使用标准库。
- `data/`：UTF-8 编码、首行为字段名的逗号分隔资料。空字段表示资料未提供，不代表数值为零或业务状态已否定。
- `tests/`：检查资料可读性，并对内容分类、结论日志、传播范围与覆盖分析的行为作出断言。

日期使用 ISO 8601 写法；时间字段为空时表示该记录没有提供时间。金额和计数字段以文本保存，具体解释须结合字段名及记录上下文。

## 运行与检查

需要 Python 3.11 或更高版本，无第三方运行依赖。

- `python3 -m unittest discover -s tests`：运行全部检查。
- `python3 -m content_impact`：输出文本分析报告（`--data-dir` 指定资料目录，`--asset A-2` 只看单个素材，`--json` 输出结构化结果）。

## 分析语义

### 内容关系分类（`classification`）

按来源与编辑方式把素材切分为"承诺谱系"，而不是按素材编号或文本相似度统计：

- **同源转载**：同一来源、内容一致（`content_hash` 相同）。
- **同源变体**：同一来源、仅文案级改动（如 `caption_changed`），关键承诺未变，与原素材同属一段承诺谱系。
- **实质改写**：`claim_changed` 开启新的谱系段，关键承诺已改，**不自动并入**原谱系的处置范围，只作为需单独复核的关联内容呈现。
- **仅主题相近**：`similar_topic` / `topic_similar` 的素材不进入任何谱系，避免把常见表达误当成同一内容。

分类只描述内容关系，用于圈定传播范围与提示复核对象；**违规结论只能来自人工审核决定，系统不凭相似度自动认定违规**。

### 处置需求与覆盖（`scope`）

- 投放的处置需求：`REQUIRED`（素材本人工结论为限制传播）、`RECOMMENDED`（同谱系其他素材被限制而推导的建议，待人工确认）、`NONE`。
- 覆盖状态：`COVERED`（措施已执行）、`OUTSTANDING`（已请求待执行）、`GAP`（未请求措施，即覆盖缺口）。`active_to` 为空的投放视为仍在传播，缺口报告中排在前面。
- 内容版本经投放关联到账号、直播场次、曝光记录与订单；订单经 `placement_ref` 归属，无法归属到具体投放的订单单独列出，不计入范围统计。

### 结论变更（`decisions`）

- 审核结论以追加方式记录，同一素材以 `reviewed_at` 最新的一条为有效结论；历史结论全部保留。
- 结论改变后用新的结论日志重新调用 `analyze()` 即可重算待处理范围与影响统计。
- 内容被复核为普通介绍（`cleared`）后：未执行的建议措施列入"建议撤回"；已执行的措施不撤销，其触达的曝光、订单及**当时的依据结论**在报告中可解释，依据被取代时会标注。

## 数据文件

- `data/assets.csv`：素材版本（来源、版本、内容哈希、编辑方式）。
- `data/decisions.csv`：人工审核结论（限制传播 / 待复核 / 普通介绍）。
- `data/placements.csv`：投放（素材 × 账号 × 直播场次，含起止时间）。
- `data/exposures.csv`：曝光记录（投放、观众组、计数）。
- `data/actions.csv`：处置措施记录（投放、状态、请求与完成时间、依据的结论）。
- `data/orders.csv`：订单（归属投放或仅归属场次、金额）；文件缺失时分析降级为无订单资料。
